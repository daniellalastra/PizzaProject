# Pizza Project

A command-line pizza ordering system built in Python.

## Features
- Choose from Small, Medium, or Large pizzas
- Select toppings and specify which half of the pizza they go on
- Enter customer info including name, phone, email, and delivery address
- Choose between pickup or delivery
- Receive an order summary with a randomly generated order number

## How to Run
```bash
python3 PizzaProject.py
```

## Example Order
- Large Pizza with Pepperoni on the First Half and Mushrooms on the Whole Pizza
- Delivery to your address
- Random order number generated at checkout
